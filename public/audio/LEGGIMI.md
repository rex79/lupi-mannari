# Suoni del tavolo

Metti qui i file audio: `ambienti/` per i sottofondi in loop, `effetti/` per i suoni brevi.
I nomi dei file e il volume di ognuno sono in `suoni.json`: puoi cambiarli liberamente.
Un file che manca viene saltato, quindi puoi aggiungerli un po' alla volta.

Formato consigliato: **mp3** (funziona in tutti i browser). Per i loop scegli file che
"girano" senza stacchi, cioè dove la fine si ricollega bene all'inizio; il gioco li ripete
senza pause. 1–3 minuti di loop bastano.

## Dove trovarli

- **Freesound** (freesound.org): enorme e ottimo per ambienti ed effetti. Ogni file ha la sua
  licenza: con **CC0** puoi usarlo come vuoi; con **CC BY** devi citare l'autore (annotalo
  in fondo a questo file). Serve un account gratuito per scaricare.
- **Pixabay** (pixabay.com/sound-effects e /music): suoni e musiche utilizzabili gratuitamente
  secondo la licenza di Pixabay, senza obbligo di citazione.

Per tagliare o rendere ciclico un file va benissimo Audacity (gratuito): taglia in un punto
"tranquillo", applica una breve dissolvenza all'inizio e alla fine ed esporta in mp3.
